# handoffs/history/

Um arquivo por handoff, nome `AAAA-MM-DDTHHMMSSZ.md` (hora UTC; sufixo `-2`, `-3` em colisão).
Nunca sobrescreva nem apague um snapshot. `handoffs/latest.md` é a cópia integral do mais recente
(ou, no formato do kit "Use Both", um ponteiro de uma linha para ele). Quem grava: skill `session-handoff`.
