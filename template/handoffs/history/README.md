# handoffs/history/

Um arquivo por handoff, nome `AAAA-MM-DDTHHMMSSZ.md` (hora UTC; sufixo `-2`, `-3` em colisão).
Nunca sobrescreva nem apague um snapshot. `handoffs/latest.md` é o índice dos trabalhos abertos com um ponteiro para o mais recente
(no formato do kit "Use Both", um ponteiro de uma linha). Fechados: `handoffs/fechados.md`. Quem grava: skill `session-handoff`.
